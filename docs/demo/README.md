# Interface walkthroughs

These 20-second animations show the app's native demonstration views. They are a visual guide, not a recording of a live account import or a benchmark of how long an import takes.

Each animation holds five scenes for four seconds each: `welcome`, `ready`, `success`, `opened`, and `verified`. The views were exported on macOS at native 4× resolution, then reduced to 880 × 960 pixels for a 440-pixel README display.

English and Simplified Chinese versions are provided in light and dark appearances. macOS permission dialogs and server responses depend on the real environment; see the main README for the full workflow and requirements.
